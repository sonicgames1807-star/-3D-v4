# Краткая инструкция

## Запуск в Windows 10/11

1. Установите Python 3 и современный Chrome или Edge с WebGL 2.
2. Распакуйте папку приложения.
3. Дважды нажмите `run.bat`. Откроется `http://localhost:8000`; чёрное окно сервера оставьте открытым, пока работает приложение.
4. Нажмите «Открыть модель» и выберите STL, OBJ, PLY, OFF, glTF или GLB либо сначала нажмите «Открыть пример».

Размер файла — до 1 ГБ (1024 МБ), но геометрия ограничена 2 000 000 треугольников и 6 000 000 вершин. Для файлов больше 120 МБ приложение предупреждает, что импорт может потребовать несколько гигабайт оперативной памяти. Бинарный STL с числом треугольников выше предела отклоняется по заголовку до чтения всего файла. Импорт выполняется локально в браузере; сеть для загрузки или отправки модели не используется. На сетках больше 100 000 треугольников кисть работает по одному клику: нажмите кнопку «Включить кисть», выберите радиус, затем кликните по нужной области и дождитесь завершения фоновой обработки. Для больших сеток отключены упрощение, каркас и диагностика границ.

Для ручного запуска откройте терминал в папке проекта, выполните `python -m http.server 8000 --bind 127.0.0.1`, затем откройте `http://localhost:8000`.

## Работа с моделью

- ЛКМ — вращать; ПКМ — панорамировать; колесо — приблизить или отдалить; «Вписать» — центрировать в кадре.
- Во вкладке «Сглаживание» выберите силу и число проходов. «Защищать открытые края» уменьшает смещение граничных вершин. Операция работает на копии; её можно отменить.
- Во вкладке «Кисть» включите режим, настройте радиус/интенсивность и нажимайте или ведите ЛКМ по видимой части поверхности. Отпустите кнопку, чтобы завершить один мазок. Повторный клик по кнопке выключает режим.
- Во вкладке «Упростить» задайте процент сокращения. Алгоритм кластеризации приблизительный, поэтому фактическое число может отличаться.
- Включите «Сравнить до / после», чтобы временно показать исходник. Геометрия исходника сохраняется в памяти текущего сеанса.
- Ctrl+Z / Ctrl+Y — отменить / повторить; Ctrl+O — открыть; Ctrl+S — экспортировать копию.
- «Сохранить копию»: выберите формат STL binary, OBJ или PLY ASCII в верхней панели. Создаётся новый файл с суффиксом `_processed`; исходный файл не заменяется.

## Что не поддерживается

Приложение не ремонтирует отверстия и самопересечения, не гарантирует пригодность к 3D-печати, не сохраняет проект, UV/MTL/текстуры/цвета/анимацию и пока не открывает FBX, 3MF, USDZ или облака точек в форматах, кроме PLY. Для подробностей см. `README.md`.
